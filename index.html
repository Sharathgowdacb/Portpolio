REAL-TIME-OBJECT-DETECTION

This project is an intelligent Computer Vision system designed to analyze a live webcam stream and perform object detection in real-time. It leverages the high-speed and efficient YOLOv3 (You Only Look Once) deep learning model, which is implemented in Python using the powerful OpenCV library. This combination allows the system to accurately identify and classify a wide variety of objects within the frame on a continuous, frame-by-frame basis. The model's robustness comes from being pre-trained on the extensive COCO dataset.

BCM HOSTEL MANAGEMENT SYSTEM

This project is a comprehensive, full-stack BCM Hostel Management System designed to streamline administrative and resident-facing operations. It is built on a Node.js and Express.js backend, which serves a robust RESTful API to a dynamic vanilla JavaScript frontend. Data persistence is managed through a MongoDB database, with structured data models defined using Mongoose schemas for Students, Chiefs, and a detailed Ration Inventory system. The application features distinct, role-based portals for Admins, Students, and Chiefs, each with its own secure authentication and functionality.
